## 🎮 About The Game

**Jungle Bus Survival** is an open-world survival game where you drive an off-road bus through a dangerous jungle. Repair your bus, collect fuel, fight bears and snakes, and escape the jungle!

---

## ✨ Features

- 🗺️ **6000m × 6000m** open world map
- 🚌 **Off-road bus driving** (4-seater)
- 🐻 **Bear AI** with territory system
- 🐍 **Snake AI** with poison attack
- 🔧 **Scrap repair system**
- ⛽ **Fuel system**
- 🌙 **Day/Night cycle** (10 min day, 5 min night)
- 🌧️ **Weather system** (rain, fog, storm)
- 👹 **Horror elements**
- 🔫 **Weapon system**
- 🎒 **Inventory system**
- 🗺️ **Mini-map + Full map**
- 📱 **Mobile friendly**

---

## 🎯 How To Play

### Controls
| Key | Action |
|---|---|
| W/A/S/D | Drive bus |
| E | Interact |
| M | Open map |
| 1,2,3 | Inventory slots |
| Shift | Run |
| F | Flashlight |

### Goal
1. Find camping site
2. Repair bus (collect scrap)
3. Collect fuel
4. Survive bear + snake attacks
5. Escape the jungle
